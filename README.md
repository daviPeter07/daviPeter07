## Sobre mim

Sou desenvolvedor de software dedicado à construção de aplicações eficientes, acessíveis e preparadas para evoluir. Atuo em diferentes camadas de uma aplicação, trabalhando com interfaces, experiência do usuário, APIs, persistência, cache, filas, integrações e processamento assíncrono.

Tenho experiência com code review e responsabilidades de liderança técnica tanto no frontend quanto no backend. Já contribuí com decisões de arquitetura, definição de padrões, organização de demandas, revisão de entregas e apoio técnico aos desenvolvedores, buscando aumentar a consistência e a qualidade do trabalho realizado pelo time.

Trabalho com foco em manutenibilidade, escalabilidade e boas práticas. Entendo que uma boa solução não deve apenas funcionar, mas também ser fácil de compreender, testar, manter e evoluir com segurança. Procuro sempre relacionar as decisões técnicas ao valor entregue para o produto, para a empresa e para as pessoas envolvidas no desenvolvimento.
